01 / CAPTURE

先收下，再想清楚

一句话、一张截图、一个文件、一个链接，先丢进收件箱，不要求你当场想清楚它是什么。AI 会读一遍内容，给出它该变成任务、日程、笔记、资料还是项目的建议。确认之后才写入，原条目和产物都留得住。

  • 一句话、一张截图、一个文件、一个链接

    先收进来，不要求当场分类。

  • AI 先读，给出这该变成什么

    任务、日程、笔记、资料或项目，给一个建议。

  • 确认之后才写入

    原条目保留，产物可以撤回。

02 / ASSISTANT

先问清楚，再动手

直接问库里的日程、任务、笔记和资料，也可以让它帮你记一件刚发生的事。需要写入时，它先把结果摆在你面前，等你点确认；不想用 AI 的时候，手动记录和整理也能走完同一条循环。

  • 直接问库里的日程、任务、笔记、资料

    回答基于你真实的数据，不靠猜。

  • 需要写入时先给你看结果

    确认前不动任何文件。

  • 离线也能手动记录和整理

    AI 不可用，循环照样转。

03 / REMEMBER

看过的东西，留得下来

笔记用 Markdown 写，可以逐层蒸馏，原文只在末尾追加、不覆盖。文件资料保留简介、原文和本机位置；标签、区域和项目把它们连成一张能检索的索引。

  • Markdown 笔记，可以逐层蒸馏

    标注层级，追加下一层，不改写原文。

  • 文件附简介，原文和位置都保留

    收进来的东西仍然找得到。

  • 标签、区域、项目互相关联

    从任何一条记录都能走到上下文。

LOCAL FIRST / 数据在哪

数据在你自己的电脑上

一记录一文件，UTF-8 JSON，可读、可备份、可迁移。两个本机服务只监听 127.0.0.1，不把数据锁在云端。

data/tasks/t-0012.json

G1

文件即数据库

一条记录一个 JSON 文件，能 diff、能备份、能直接搬走。

G2

AI 只是建议层

读取、摘要、提取日期；写入前一定等你确认。

G3

只有本机能写

Zod 校验、原子写入、审计日志，写入路径只有一条。

  • 本地单用户
  • Windows 10 / 11
  • 不发布公网

FAQ / 常见问题

你可能想问

数据存在哪里？

存在你电脑上的 data/ 目录，一条记录一个 JSON 文件；卸载程序时数据会保留。

需要联网吗？

应用本身离线可用；只有向 AI 提问或让它解析内容时，才会经本机服务把请求发到模型。

AI 会自动改我的东西吗？

不会。它只产出建议，写入前一定先展示结果并等你确认。

支持手机吗？

连同一个 WiFi 时可以用手机浏览器访问；目前是本地单用户版本。

需要装 Node.js 吗？

用 Windows 安装包不需要；从源码运行需要 Node.js 20.19+ 或 22.12+。

数据能迁移吗？

能。整个 data/ 文件夹可以直接拷到另一台电脑。
