# MOBILE-P0 · 移动端全量设计稿

本目录是 Issue #5 的独立移动端设计提案，不引用或修改桌面端 DOM。入口为 `index.html`，通过底栏与「更多」覆盖 13 个路由。

## Frontend Design 视觉命题

- **目标用户**：同时处理课程、竞赛、开发和生活安排，需要在手机上单手快速判断与操作的中国大学生。
- **核心任务**：先判断「现在做什么」，再完成捕捉、澄清、执行、查看时间和回顾。
- **内容特点**：中文信息密集，时间、状态、来源和关联关系多；任务、日程、资料等实体必须快速区分但不能割裂成角色目录。
- **视觉命题：夜航仪表簿**。把个人事务系统设计成一本深色调度记录簿；时间刻度、运行信号、文件索引与连续内容面来自 KERNEL 自身的「内核 / 调度 / 文件」语义。
- **字体**：标题与关键数字使用本地 `Bahnschrift SemiCondensed` 窄体，中文正文使用 `Microsoft YaHei UI / PingFang SC`，时间和数据使用 `Cascadia Mono / JetBrains Mono`。不依赖在线字体。
- **配色**：保持既有柔暗灰阶与珊瑚信号色；强调色只标记当前、告警和操作结果，不增加无内容含义的装饰色。
- **版式**：减少相同圆角浮卡，改用左侧索引脊、非对称文件切口、连续列表面和时间网格；保持移动端左对齐与单手扫描顺序。
- **动效**：非用户触发的通用 stagger 已撤下；动效集中在导航选中、筛选切换、任务完成、详情开合和表盘指针等状态变化。
- **导航**：取消悬浮导航球，改为固定在屏幕右侧中部、视觉完全隐藏的 34×132px 边缘触控层。手指一接触就立即向左展开五分区半圆扇面并虚化背景；入口图标与文字直接落在扇面上，不使用独立圆形按钮。滑过时以珊瑚色刻度高亮分类，选中入口后松手跳转；未命中任何入口时松手，扇面立即收起并停留在当前页面。键盘 Enter / Space 可切换轮盘。
- **二级轮盘**：手指在「更多」停留约 260ms 后，一级入口退为背景，课表、项目、习惯、踪迹、个人、资料、回顾、回收站和设置沿更大的 180° 半圆展开；继续滑动并松手即可直接跳转。
- **回撤返回**：二级轮盘保持按压时，将手指滑回右侧热区的 62px 回撤范围即可收起二级节点并恢复一级轮盘；手势链不中断，可继续选择一级入口或在热区内松手取消。
- **今日节奏**：采用「调度磁带」而非钟表；分裂式大时间数字与当前行程组成主窗口，底部显示前后行程时间和队列进度，支持按钮与整卡横向滑动切换。
- **语义图标**：列表根据标题、正文关键词、URL 和文件扩展名自动匹配统一的线性 SVG 图标；快速捕捉的新内容会立即进入收件箱并触发同一套识别逻辑。
- **详情预览**：任务详情使用屏幕居中的深色毛玻璃信息窗，背景内容降亮并模糊；快速捕捉与更多导航仍保留底部面板形态。

## 信息架构提案

- 一级底栏：总览 / 收件箱 / 任务 / 日程 / 更多。采用悬浮式深色 Dock 与统一线性图标；选中项由内嵌胶囊、强调色图标和底部信号点共同表达。四个最高频动作始终一跳可达；「更多」承载低频空间，而不是挤压 390px 宽度。
- 全局快速捕捉：右上角 `＋` 在所有页面常驻，使用 bottom sheet，避免跳页打断当前上下文。
- 详情采用两级承载：轻量预览使用 bottom sheet；长内容、编辑与危险操作推入全屏层。当前稿演示第一层。
- 页面之间共享顶部标题、底栏、列表行、卡片、筛选 chip 和 bottom sheet；内容结构按移动任务重新编排，不复刻桌面栅格。

## 13 路由移动形态说明

| 路由 | 移动端保留 | 下沉 / 改造 |
|---|---|---|
| 总览 `/` | 今日焦点、系统信号、下一步、今日节奏 | 桌面监控柱压缩为 2×2 信号卡；项目全量列表下沉 |
| 收件箱 `/inbox` | 捕捉、未处理流、逐条澄清 | 批量操作下沉；澄清表单放 bottom sheet |
| 任务 `/tasks` | 今天/本周筛选、完成、快速新建 | 复杂筛选进入二级面板；详情先预览后全屏 |
| 日程 `/calendar` | 周条、今日议程、空闲窗口 | 月历和跨周操作下沉；取消桌面时间网格 |
| 课表 `/timetable` | 当前周、按日课程列表 | 完整周矩阵改为按天展开，减少横向扫描 |
| 项目 `/projects` | WIP 信号、项目进度、下一步 | 四列看板改为纵向优先级流 |
| 习惯 `/habits` | 今日打卡、连续天数、14 日点阵 | 长周期统计与编辑下沉 |
| 踪迹 `/traces` | 按日时间流、快速查看 | 大图与筛选进入详情 |
| 个人 `/profile` | 身份、周信号、当前关注 | 完整统计与标签管理下沉 |
| 资料 `/library` | 搜索、类型筛选、最近使用 | 三栏阅读器改为列表 → 全屏阅读 |
| 回顾 `/review` | 开始回顾、核心指标、待处理信号 | 五步流程进入独立全屏层 |
| 回收站 `/trash` | 最近删除、恢复入口 | 彻底删除需要二次确认 |
| 设置 `/settings` | 外观、系统、隐私、关于 | 分组长表单改为列表 → 分页设置 |

## Token 映射

| 移动稿用途 | 现有 token |
|---|---|
| 页面背景 / 下沉面 | `--bg` / `--surface-sunken` |
| 卡片 / 浮层 | `--surface` / `--surface-elevated` |
| 主文 / 次文 / 安静文字 | `--ink` / `--ink-2` / `--muted` |
| 激活与高风险信号 | `--accent` / `--accent-text` |
| 成功、警告、危险 | `--success` / `--warning` / `--danger` |
| 软边缘 | `--outline` / `--outline-strong` |
| 卡片深度 | `--shadow-card` / `--shadow-highlight` |
| 卡片 / 内部件圆角 | 16px / 12px（映射现行规范） |
| 触控目标 | 44px 最小尺寸 |

未新增品牌色；所有颜色值与 `docs/03-DESIGN-SYSTEM.md` 一致。

## 交互覆盖

五个核心页（总览、收件箱、任务、日程、资料）可从屏幕右侧隐形触控层呼出五分区半圆扇面；滑动命中后松手跳转，未命中则松手取消，「更多」可在同一手势中进入二级扇面。总览「今日节奏」一次聚焦一个行程，可横向滑动或使用前后按钮切换；收件箱与任务筛选会切换真实列表内容；日程支持七日逐日选择和空态；资料支持类型筛选与即时搜索；任务可完成/恢复并更新进度；全局快速捕捉可写入原型内存态收件箱；列表项可打开居中毛玻璃详情；遮罩与 Escape 可关闭。动效只响应用户动作，并尊重 reduced motion。其余八页为中保真静态结构，保留导航和详情入口。

## 自检口径

- 目标视口：390×844，补充 360×800。
- 页面级 `scrollWidth <= clientWidth`。
- 可交互控件最小 44×44，包含筛选 chip 与图标按钮。
- 不依赖 hover；所有主要动作支持点击、键盘焦点和可见焦点环。
- 尊重 `prefers-reduced-motion`。
- 原型不访问 API、不读取或写入 `data/**`。
