01 — 第一次接触

30 秒理解

KERNEL 是一个本地优先的个人事务内核。它把你散落的想法、待办、日程、项目与资料收进同一个循环里。

核心循环只有五步：

01捕捉 → 02澄清 → 03组织 → 04执行 → 05回顾

侧栏的八个页面，就是这条循环的展开——收件箱负责捕捉，任务与项目负责澄清和组织，总览与日程负责执行，回顾负责收口。

所有数据都在本地的 data/ 目录里，一条记录一个 JSON 文件，可读、可 diff、可备份。网页只是驾驶舱，不是数据的所有者；AI 也只是协作者，永远不越过你直接改数据。

04 — 地图

八个页面速览

每个页面各司其职，对应循环里的一段。先记住一句话，细节用久了自然熟。

总览

OVERVIEW

今天该做什么，先看这里。

  • 工作台：已结束日程 →「现在 · HH:mm」分界 → 下一步行动 TOP5
  • 状态条：下一项 / 收件箱 / 逾期 三段等宽，点哪段就去哪页
  • AI 对话盒：直接问「我今天有什么特别紧急需要做的事」，它读库作答
  • 监视柱：收件箱水位、WIP 上限 3、连续刷题点阵、完成趋势、到期负载
  • 工作台任务与项目条点开就地弹详情，不跳页、不丢位置

收件箱

INBOX

一切先到这里，再决定它是什么。

  • 快速捕捉，一句话回车即可
  • 文件投递：拖拽或点回形针选择文件，先入收件箱，AI 先读一遍
  • 水位 ≤8 健康、>8 超阈，该澄清了；按 今天 / 昨天 / 更早 分组
  • 五项澄清操作；AI 解析过程流式可见，结果收起再展开不丢
  • 批量条：批量 AI 解析 / 批量 → 任务 / 批量丢弃；滚出视口时贴右缘浮动跟随

任务

TASKS

所有「要做的事」都在这里。

  • 计数：未完成 / 逾期 / 今日
  • 筛选：状态 / 时间 / 更多（上下文 · 能量 · 区域 · 身份）；分组：平铺 / 按项目 / 按上下文
  • 快速新建：只填标题回车 → 弹窗预览 AI 补全，全部字段可编辑，点「创建任务」才写入
  • 详情弹窗与总览就地弹窗共用同一份详情；可标记完成 / 查看项目 / 编辑 / 删除（撤销进回收站）

日程

CALENDAR

时间维度上的安排与场次。

  • 今天 / 明天 / 本周 / 下周 / 更远 议程流
  • 「下一项」倒计时卡
  • 迷你月历，标注今日与有安排的日期
  • 「今天」「回到现在」两个定位按钮

项目

PROJECTS

需要多步完成的事，装在这里。

  • 进行中 / 暂停 / 将来 / 已完成 分组列表
  • 每行有「下一步」与进度；输入标题回车即可快速新建
  • 详情弹窗含任务清单，可标记完成并撤销；行可点开就地弹详情，并可编辑 / 删除

资料

LIBRARY

知识的内存：笔记与资料。

  • 全部 / 笔记 / 资料；类型 / 状态 / 标签筛选（标签条按使用多少排序，全部列出、不再截断）
  • 资料状态五档（未读 / 在读 / 读完 / 参考 / 归档）弹窗内快捷设置，每档附判断标准
  • 笔记蒸馏层级 L0–L3 同样可设（L0 原文 → L3 永久）
  • 阅读弹窗 +「关联」；文件类资料可打开文件 / 在文件管理器中定位；可编辑 / 删除

回顾

REVIEW

每周心跳，给这一周收口。

  • 周回顾 / 月回顾两张卡并列一栏，排在能量分析之上
  • 指标瓦片：捕获 / 新增 / 完成 / 逾期
  • 点「AI 解析」生成七段报告（默认阅读视图分节呈现，「编辑」可切换编辑）：结论速览 → 数据解读 → 趋势对比 → 问题诊断 → 值得保留 → 下期行动 → 风险预警
  • 报告历史按时间倒序自动归档，点开即可阅读、可删除
  • 停滞项目独立一栏，可迁移或归档（真实落盘，可撤销）

设置

SETTINGS

系统自身的配置与状态。

  • 外观（亮 / 暗）
  • AI 集成（在线状态）
  • 标签管理：列出全部标签（来源 / 使用计数 / 登记时间），可重命名（级联）、合并、删除（使用中会拦下并给出计数）；可一键「扫描并登记」历史未注册标签
  • 数据统计
  • 数据服务（最近活动）；关于
05 — 协作者

AI 怎么帮你

AI 走本地的 opencode（127.0.0.1:4096），不出本机。它做的事不多，但都在关键处：把一句话补成能用的事务，把一周收成一份能读的报告，把散在库里的东西替你答出来。

收件箱 AI 解析

对一条未澄清内容，AI 给出结构化建议：目标 / 标题 / 上下文 / 能量 / 重要性 / 预估 / 截止 / 理由，并给出挂接建议（挂到哪个项目、归入哪个区域、加什么标签）。解析过程是流式可见的——你能看到它在连接、思考、生成，而不是一个转圈的空等。

选中的多条可以一次性「批量 AI 解析」，逐条顺序进行、进度写在中途；某一条失败不影响其余。结果绝不自动应用，收起再展开也不会丢；批量解析期间切到别的页面再回来，进度与「AI 建议就绪」标记仍在。文件条目会先被 AI 读一遍：文本文件与 Word / PowerPoint / Excel 文档（.docx/.pptx/.xlsx）读前八千字摘录，PDF 等其余只凭文件名与元数据判断。

对话盒：直接问库里的事

总览的对话盒读整库回答你，比如「我今天有什么特别紧急需要去做的事情」。它按逾期 → 今日到期 → 日程的顺序给出最紧急的几件，话不多，但都落在库里的真实记录上。

清空对话不是删掉——它会先把这轮记录归档成一条按时间命名的笔记，从 toast 就能跳到资料库查看。归档成功，才会清空。

快速新建：先确认，再写入

在任务页只写一个标题回车，会先弹出确认窗口；AI 在窗口里安静地补全字段（上下文、能量、重要性、预估、截止、项目、区域、标签），你可以任意修改。只有点「创建任务」，数据才会写入。按 ESC、点遮罩或「取消」则什么都不写；AI 迟到或失败也不影响你继续填写与创建。

标签是「录入即生成」的。你在任务 / 项目 / 笔记 / 资料里写下的新标签，会在落盘时自动登记进标签表（来源、首次使用、登记时间都留痕）；AI 在确实找不到合适已有标签时，也可以提议一个新的主题标签（最多 3 个、每个不超过 12 字），你应用后才登记。注册表里已有的标签，AI 会优先复用。

回顾报告（周 / 月）

回顾页的周、月两张卡各有「AI 解析」。点一下，AI 读整个系统生成一份七段结构报告：结论速览、本期数据解读、趋势与对比、问题诊断、值得保留、下期行动、风险预警——每个判断都带具体数字或对象，叙述优先用对象标题、绝对值一律带对比基准，行动写成「如果…，那么…」并注明何时完成、完成标准是什么。打开报告默认是阅读视图（七段分节、舒适行距），点「编辑」才切到文本框修改，点「完成」回到阅读；「下期行动」段只留一句指针（「见决策区（N 条）」），完整行动都在下方「决策」里，不重复。

进行中的周期按同期等长窗口对照：月是「本月 1..N 日 ↔ 上月 1..N 日」、周是「本周至今 ↔ 上周同期」（短月自动截断），月末 / 周初不会拿几天去比一整个上期；窗口未走完时报告会自然说明。每次生成都会按时间自动归档到「报告历史」：随时点开阅读（同样分节呈现）、可删除；编辑后点「保存回顾」更新同一条，不会重复堆记录。

三条红线

01只出建议 — AI 从不直接改你的数据。
02确认才写入 — 任务 / 项目等记录只有你点「应用建议」「应用」或「创建任务」才落盘；回顾报告生成即自动归档（可删除、编辑保存更新同一条）。
03随时撤销 — 每次写入都带着 5 秒的撤销窗口。
06 — 联动

系统是连起来的

系统和系统之间不是孤岛。每个详情弹窗的底部都有「关联」区块，显示我指向谁与谁指向我两组链接，点击可以互相跳转。

此外，地址栏支持深链，任何一条内容都能被直达，适合收藏或分享给未来的自己。关闭弹窗时会自动清掉参数。

/tasks?task=…直达某条任务的详情弹窗
/projects?project=…直达某个项目
/library?note=…直达某条笔记（AI 对话归档也走这里）
/library?resource=…直达某份资料
/calendar?event=…直达某个日程事件
/trash回收站：恢复或彻底删除
07 — 心法

用好它的心法

工具本身不复杂，难的是持续对。这几条是这套系统的使用纪律。

水位 ≤8收件箱超过 8 条就先澄清再干活，别让它变成第二个待办堆。
WIP ≤3进行中的项目最多 3 个，超了就收口，而不是继续开新的。
迁移即重决策每周回顾时，过期或停滞的项必须迁移或丢弃，不许无声堆积。
能量匹配低能量时做 @phone 这类低耗任务，而不是硬啃大块工作。
撤销兜底完成、澄清、批量、AI 应用——5 秒内全可撤，放心操作。
清空即归档对话清空不是删除：先归档成一条笔记，想找回就去资料库。
建议要你点头解析、快速新建——AI 只给建议，落盘永远等你点「应用建议」「创建任务」。回顾报告生成即自动归档（可删除），编辑保存更新同一条。
周回顾是心跳每周固定一晚，短、可视。系统靠它维持节奏。

09 — 排障

常见问题

遇到问题先看这里，多半是服务没起来。

数据在哪？

全部在 data/ 目录下，一条记录一个 JSON 文件；data/activity.jsonl 是审计日志，每次变更追加一行。

想重置示例数据？

运行 npm run seed -- --force。它会重新生成种子数据（维护用，绕过服务）。

状态条显示「AI: 离线 · opencode 未启动」

npm run dev 会自动拉起 opencode serve；若你单独启动前端，也可以手动运行 opencode serve --port 4096。

写入失败？

先确认数据服务在跑：用 npm run dev 启动（数据服务在 127.0.0.1:4097）。服务离线时页面只读，写入会显式报错。

手机能访问吗？

可以，但仅限可信 WiFi。数据服务与 opencode 都只监听本机，不直接暴露到局域网。

清空对话后，之前聊的去哪了？

没有丢。清空对话会先把整段记录归档成一条笔记（标题形如「AI 对话归档 · 时间」），在「资料」页就能翻到。你可以点 toast 上的「查看」直接跳过去；归档成功，对话才会清空。

AI 的建议会自动应用吗？

不会，任何建议都要你点头。收件箱解析、任务快速新建的补全都只是建议——只有你点「应用建议」「创建任务」，任务 / 项目等记录才会写入，且写入后 5 秒内可撤销。回顾报告是个例外：生成即自动归档（可删除、可编辑后保存更新同一条）。收件箱的建议还可以先「编辑」成你要的样子再应用。

误删了怎么办？

删除都是软删除，先落入「回收站」（侧栏可进，或直达 /trash）。在回收站里点「恢复」即可；要彻底删掉，需要再点一次确认。删除后 5 秒的 toast 里也带「撤销」。
