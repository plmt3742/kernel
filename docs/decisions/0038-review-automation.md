# ADR-0038 · 回顾自动化——周期调度自动生成 + 迁移建议持久化

- 状态：已采纳
- 日期：2026-10-05
- 相关：ADR-0007（AI 周回顾）、ADR-0013（七段报告 + 生成即自动归档）、ADR-0022（界面状态保留）、ADR-0032（AI 整理每日调度先例）

---

## 1. 背景

「回顾自动化（自动汇总 + 停滞清单 + 迁移建议）」是 v0.6 功能缺口之一。此前：周 / 月回顾必须手动点「AI 解析」；服务端指标与停滞清单虽已是确定性聚合，但只有被点击时才计算；AI 产出的 `staleAdvice`（停滞项目处置建议）只在草稿响应里短暂存在，归档时被丢弃（`reviewSchema` 只存 `staleProjectIds`），历史报告无法回看建议。ADR-0032 已为「AI 整理」建立每日调度先例（12:00 后、跨标签锁、会话守卫、AI 离线静默）；本 ADR 复用同一机制解决回顾的自动化。

## 2. 决策

### 2.1 调度语义（`src/lib/review.ts` · `useReviewScheduler`，`AppLayout` 挂载）

| 门闸 | 规则 |
|---|---|
| 触发时机 | 周一 12:00 后首次 tick 生成**周回顾**（当前 ISO 周）；每月 1 日 12:00 后首次 tick 生成**月回顾**；均叠加「每日 12:00 门闸」（上午不跑） |
| 到期判定 | 运行时派生、绝不落盘：`weeklyDue = hours ≥ 12 && now ≥ startOfWeek(now) + 12h`；`monthlyDue = hours ≥ 12 && now ≥ 本月 1 日 12:00` |
| 去重真相 | 数据即真相：`getReviews()` 已存在同 `periodKey` 的归档（**任意来源** manual / ai）→ 跳过；不持久化「上次跑过」类派生状态 |
| 防重 / 防风暴 | 会话内 `attemptedPeriodKeys`（探活**前**置位，AI 离线不重复探活 / 生成）；跨标签锁 `kernel.ui.review.lock.v1`（TTL 120s）；取得锁后**先重新水合**再复查归档存在性（防他标签刚生成的窗口） |
| 前置条件 | `getDataSource() === 'server'`（未水合不跑，避免以空快照误判） |
| 成功路径 | `generateReviewDraft(period)`（服务端已自动归档）→ `hydrateFromServer()` → toast「已自动生成本周回顾 · 查看」 |
| 失败路径 | 静默（与 organize 一致，不打扰用户、不 toast 报错） |

一次 tick 只处理一个周期（周优先于月）；周 / 月各自「每周期一次」。

### 2.2 迁移建议持久化

- `reviewSchema` 增可选 `staleAdvice`（`staleAdviceSchema`：`projectId` + `action ∈ archive|migrate|reactivate` + `reason ≤200`）；`staleAdviceSchema` 前移至 `reviewSchema` 之前定义（避免 TDZ）。
- 写入路径：draft 自动归档时随报告写入；手工 `POST /api/reviews` 可透传（`sanitizeStaleAdvice` 清洗，非法形状**静默丢弃、绝不 500**）；`POST /api/reviews/:id/update` 白名单**不变**（建议随版本生成、不参与编辑）。
- 展示：归档报告阅读视图新增「迁移建议」块，复用既有处置动作（归档 / 迁移 / 重启）；草稿面板行为不变。

### 2.3 边界（明确不做）

- **不自动应用任何建议**——归档 / 迁移 / 重启仍需用户点击；
- 不新增端点（复用既有 `POST /api/ai/review/draft`）；
- 不改 `update` 白名单；不持久化调度派生状态；不新增依赖。

## 3. 后果

- **正面**：打开应用即得本周 / 本月报告与建议，历史建议可回看；跨标签 / 重复生成由「数据 + 锁 + 会话守卫」三重防重；AI 离线零打扰。
- **取舍**：周一 12:00 后生成的「本周回顾」只含周一至当天数据（与手动点击同口径；之后可手动重新生成新版本）；若整周未打开应用，本周不补跑（补跑 = 打开后的当前周期，符合「过点打开即补跑」语义）。
- **数据**：review 行新增可选字段，旧记录 / 旧版本前端不受影响（optional，无迁移）。

## 4. 验证

`.qa/v76/qa-ws5.py`（Playwright 假时钟 + `/api/**` 拦截隔离）**25/25 PASS**：周 / 月候选选择与成功 toast、同周期仅一次（会话守卫）、已有归档（含 manual 来源）零动作、09:10 / 11:29 静默且过 12:00 触发、AI 离线不生成且探活不风暴、归档「迁移建议」展示。同批前端回归 `.qa/v76/qa-b.py` **40/40 PASS**（隔离运行，真实数据零触达）。
