# 09 · 风险登记

> 本文是 KERNEL 的风险台账，供所有者与协作者共同维护。
> 规则：新风险随时登记、编号续增；每两周或重大变化时复核；关闭时标注日期与结论。
> 等级：**高**（阻断 / 可能丢数据或泄密）/ **中高**（需排期处理）/ **中**（需管理）/ **低**（关注）。

## 维护规则

1. **登记即入台账**：发现风险先加一行，再讨论怎么处理。
2. **编号续增**：`R1`、`R2`……不复用、不删行；关闭时把「状态」改为「已关闭（日期 + 结论）」。
3. **关联优先**：优先写 ADR / 工单 / 文档章节号，便于追溯；不要只写「以后再说」。
4. **触发信号必须可观察**：写清楚看到什么就说明风险正在发生。
5. **每两周或重大变化时复核**：与 `TASK_BOOK.md` 的下一会话待办同步更新。
